# 组件规格索引

**72 项设计系统能力：P0 26 项、P1 28 项、P2 18 项。**其中包含配置、布局、子组件组合与反馈服务；不是 72 个已发布组件。所有项目当前均为待实施。正式 1.0 的目标是 P0+P1 共 54 项，P2 后续按 RFC 逐项加入。

先读 [组件通用规格](../docs/26-组件通用规格.md) 与 [跨框架 API](../docs/04-跨框架API与类型契约.md)。每项均包含 props、事件、部位、状态、移动端、无障碍、主题 token 和专项验收。

## 10 项纵向试点

ConfigProvider、Button、Icon、Input、Checkbox、Form、Dialog、Toast、Flex、Card。先完成两框架的真实端到端示例，再扩展组件数量。试点不要求提前导出 P1/P2；必要图形、loading 标记可以用已批准的内部原语，不依赖未完成公共组件。

## 扩展规则

子组件（例如 CheckboxGroup、FormField）归属于对应主规格，不能重复计入 72 项。新增组件先补一份 RFC/规格并说明与现有功能的差异；不得为了充数量拆分纯别名。全部能力矩阵及完成证据在 [任务追踪](../tracking/TASKS.md) 维护。
