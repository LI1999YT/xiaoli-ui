# 27｜未来 npm 使用者指南（API 目标示例）

以下示例定义拟建组件库的使用体验。包尚未发布，名字是占位符；应在对应组件实现后将这些例子转成可编译 fixture。不能现在就宣称运行这些 npm install 能安装本库。

## 1. React

```sh
npm install @your-scope/ui-react
```

```tsx
import { useState } from 'react';
import { ConfigProvider, Button, Input } from '@your-scope/ui-react';
import '@your-scope/ui-react/style.css';

export function App() {
  const [name, setName] = useState('');
  return (
    <ConfigProvider theme={{ id: 'brand-a', mode: 'light' }}>
      <label htmlFor="demo-name">姓名</label>
      <Input id="demo-name" value={name} onValueChange={setName} />
      <Button onClick={() => console.log(name)}>读取输入</Button>
    </ConfigProvider>
  );
}
```

React/react-dom 由应用自行安装到支持的匹配版本，库不内置另一份。例子的 console 只演示事件，不作为业务遥测。

## 2. Vue

```sh
npm install @your-scope/ui-vue
```

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { ConfigProvider, Button, Input } from '@your-scope/ui-vue';
import '@your-scope/ui-vue/style.css';
const name = ref('');
const printName = () => console.log(name.value);
</script>

<template>
  <ConfigProvider :theme="{ id: 'brand-a', mode: 'light' }">
    <label for="demo-name">姓名</label>
    <Input id="demo-name" v-model="name" />
    <Button @click="printName">读取输入</Button>
  </ConfigProvider>
</template>
```

不要求全局 app.use 安装所有组件。明示 package imports，使用者可以只引入自己的框架。

## 3. 完整主题

```ts
import { defineTheme } from '@your-scope/ui-theme';

export const brandTheme = defineTheme({
  id: 'brand-b',
  mode: 'dark',
  density: 'comfortable',
  tokens: {
    'color.action.bg': '#6d28d9',
    'color.action.fg': '#ffffff',
    'radius.md': '12px'
  },
  components: {
    button: { radius: '999px' }
  }
});
```

这是拟定 token API，具体键由 schema 生成并在实现时校验。演示色值不代表完整主题已通过对比度检查。直接导入 ui-theme 时，建议在应用 package.json 显式声明该包依赖，不依靠包管理器碰巧提升的传递依赖。

## 4. 实例与部位

React：`<Button className="buy-button" classNames={{label:'buy-label'}} />`。Vue：`<Button class="buy-button" :class-names="{label:'buy-label'}" />`。完整示例还应提供有意义的按钮内容，不能把空按钮作为可访问示范。

局部 token 可以通过 typed style helper 设置；TypeScript 不认识自定义 CSS 属性时使用本库导出的受限 `CSSVariables` 类型，不建议 `as any`。

## 5. 按需样式

从 ui-react/button 或 ui-vue/button 引入 Button，同时导入 base.css 和 button/style.css；不要同时导入全量 style.css。复杂组件 CSS 子入口会包含必要组件依赖，详见构建规范。

## 6. 常见约定

Input React 用 value/onValueChange；Vue 用 v-model。Dialog React 用 open/onOpenChange；Vue 用 v-model:open。Checkbox React 用 checked/onCheckedChange；Vue 用 v-model。非受控使用 defaultValue/defaultChecked/defaultOpen。

清空 Input 得到空字符串，Select 单选得到 null，多选得到 []。库不主动提交你的业务请求；Toast 通过 Provider 下的 useToast() 获取，不使用跨应用全局单例。

## 7. 原生平台与 SSR

这是 Web DOM 组件，不直接适配 React Native 或小程序原生组件。Next/Nuxt 安装后按 SSR 文档设置 Provider 与 CSS，不盲目关闭 SSR 逃避问题。使用旧 CJS 项目先看 ESM-only 边界。
