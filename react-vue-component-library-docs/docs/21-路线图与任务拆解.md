# 21｜路线图与任务拆解

不根据 AI 的一次输出承诺交期。按照退出条件推进，前一阶段没有贯通就不增加组件数量。

## M0｜工程底座

确定 scope 占位和实际 repo 信息；锁定依赖组合；建立 workspace、4 个公共包和私有基础包；实现 scripts；建立 tokens/schema、基础 CSS、双框架 playground；建立测试/类型/pack/consumer 架子。

退出：干净目录安装并构建；框架运行时 external；tarball 无 workspace/private 泄漏；两个 fixture 均可消费最小导出；没有伪造 npm 发布。

## M1｜10 项纵向试点

ConfigProvider、Button、Icon、Input、Checkbox、Form、Dialog、Toast、Flex、Card。每个组件 React/Vue 同步完成，不先做完整 React 版再拖延 Vue。

做一个可操作的示例：输入和勾选 → 表单验证 → 打开确认 Dialog → 提交反馈 Toast；两个不同主题并存，弹窗随主题变化；键盘、触屏、reset、受控和 unstyled 可用。

退出：10 项的类型、状态、文档、契约测试、基础移动测试与本地打包都通过。M1 只是内部试点，不宣布 P0 26 项已完成。

## M2｜P0 完整内测

补完其余 16 项 P0，共 26 项；双框架 SSR fixture、完整浮层栈、基础国际化、CSS 按需与清晰文档。准备本地/预发布候选包，公开 next 仍需所有者授权。

退出：P0 全部状态可用，关键 a11y/性能/消费端验证有证据；没有“函数已导出但里面 return null”的空壳。复杂Select/Form/Dialog为重点回归。

## M3｜P1 与 1.0 候选

按依赖顺序增加 28 项 P1：先展示/导航，再数值和上传，再日期/表格，最后移动专属组合与通知。总计 P0+P1 54 项，不把 P2 自动带入 1.0。

退出：完整质量门禁、真实 npm 安装验证、关键真机/读屏记录、API 冻结与迁移说明、开源资料与发布安全配置。未完成高风险项时保持 beta 或调整正式承诺清单，不能偷偷删测试。

## M4｜P2 按需求扩展

18 项：树/级联/穿梭、虚拟化、滚动/手势、轮播、搜索/滚轮选择等。先用 RFC 评估复杂度、无障碍、包体、SSR 与移动交互，再逐项加入。实验模块独立标记，不进入稳定导出前通过验收。

## 任务依赖

```text
tokens → theme → ConfigProvider
core 状态 → Input/Checkbox → Form
DOM/focus/layers → Dialog/Popover → Select/Dropdown/DatePicker
Card/List/Pagination + 纯数据推导函数 → Table（v1 非虚拟）
Drawer/layers → BottomSheet → ActionSheet/Picker
集合索引 → Tree/Transfer → TreeSelect/Cascader
滚动基础 → VirtualList → 各组件可选虚拟化
```

## 每个任务的完成定义

读规格 → 确认公共 API → 先写关键测试 → 实现共享逻辑 → React/Vue 适配 → 共用 CSS → 类型/示例 → edge cases → 打包/消费 → 审查 → 更新追踪。一次提交只包含同一任务或紧密关联底座；未通过不得把状态写 done。
