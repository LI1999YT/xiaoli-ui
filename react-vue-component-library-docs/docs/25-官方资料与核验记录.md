## 当前核验后特别提醒

npm OIDC 不等同任意 CI 都可用；npm CLI/Node 有最低要求，配置直接 publish 的权限必须正确。provenance 不是对所有私有仓库自动可用。GitHub Actions 的版本不在模板中胡填，实施时查证并固定 SHA。

Vite 文档已出现新的底层构建选项名称；按实际锁定版本编写。Changesets GitHub 旧文档指向新的官方文档站，本文采用新地址。
