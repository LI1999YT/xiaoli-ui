# 11｜表单与异步数据规范

## 1. v1 的 Form 范围

提供 Form、FormField、FormLabel、FormControl、FormDescription、FormError、FormActions 及类型化字段注册。支持基础规则、同步/异步 validator、受控 values、初始值、reset、submit、字段错误与触达状态。不是通用 JSON Schema 低代码渲染器。

与 React Hook Form、vee-validate、Zod 等集成作为可选适配示例，不作为所有用户必装依赖。实际适配版本在实施时核验并锁定；没有做过测试不写“全兼容”。

## 2. 字段和值

字段路径使用数组形式 `['profile','name']`，类型是只读的 string/number 片段，不用有歧义的点号拆分。默认值不为 undefined；字符串空值 `''`、数值空值 `null`、布尔值 false、多选空值 `[]`。

保留原生 name/required/disabled。无原生输入的选择控件需要明确的隐藏字段或 Form 序列化桥接；disabled 不参与原生提交，readonly 按组件能力保留值。不能让外层包装收到 name 而实际 input 没有。

Form 级统一 values 的 React API 为 values/defaultValues/onValuesChange；Vue 为 values/defaultValues/update:values，使用 v-model:values，不与普通单值 modelValue 混淆。

## 3. 验证合同

```ts
interface ValidationContext<T> {
  values: Readonly<T>;
  signal: AbortSignal;
  trigger: 'change' | 'blur' | 'submit';
}
type ValidationResult = string | undefined;
type Validator<V,T> = (
  value: V,
  context: ValidationContext<T>
) => ValidationResult | Promise<ValidationResult>;
```

Form 层规则使用 `readonly {path,validators}[]`，path 为字段路径片段数组；不得把数组隐式转换成对象字符串 key。字段规则的类型应通过 typed helper 保留。

默认首次 blur 后校验，首次提交时检查所有字段；字段已有错误后可在 change 复验。规则按声明顺序执行，默认返回首个错误。全表异步校验维护 field/version 或 requestId；旧请求返回时不覆盖当前结果。卸载或 reset 使旧结果失效。

不因网络失败把“用户名不可用”当确定结论。业务校验服务失败通过错误状态和重试反馈；开发错误进入报告而非静默通过。

## 4. 提交与 reset

提交链：防止默认浏览器行为（由组件模式明确）→ 标记提交中 → 验证最新快照 → 定位错误或调用 onSubmit → finally 清理状态。默认提交期间禁止重复 onSubmit，但不误禁用整个页面。用户取消操作有 AbortSignal；成功是否 reset 由业务决定。

React 用可等待的 `onSubmit`，Vue 用可等待的 `submitHandler` prop；Vue `@submit` 仅为验证成功后的观察通知，不用于推断 Promise 结束时间。两个框架均只有一个业务提交执行器；不能同时在事件与执行器里调用同一提交接口。

reset 恢复初始快照并清空 touched/dirty/errors 和 pending 请求。受控模式发出下一 values，由父应用确认更新；不得在 props 不变时假装 reset 已改变外部值。动态字段卸载默认保留值，使用 `preserve=false` 才移除；FormFieldArray 复杂重排作为扩展 RFC。

## 5. 所有远程数据组件遵守

组件接收 data/options/loading/error；不写死接口 URL、axios、鉴权头或后端格式。异步搜索发 query 事件，外部用 AbortController/序号隔离请求；loading、空数据、请求失败与没有更多分别展示，不混用 Empty。

防抖默认不对普通 Input 生效；远程搜索示例可使用 300ms 防抖作为示例值，不作为库级强制延时。切换 query、页码、筛选时是否保留旧数据由明确 prop 或业务状态决定。

## 6. Upload 特例

通过 request adapter 完成传输，支持 AbortSignal 和真实 progress 回调。重试创建新请求编号，不覆盖已删除文件；文件选择、等待、上传、成功、失败、取消各有状态。

客户端 accept/大小校验只改善体验，不替代服务端验证、授权、恶意文件检测或存储权限。库不承诺上传安全。File/ObjectURL 仅客户端创建，卸载或移除时 revoke；不在 SSR 顶层引用 File 构造器。
