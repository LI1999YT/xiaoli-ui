# 00｜项目决策与边界

文档基线：2026-09-10；状态：待实施的需求基线，不是已完成的软件。暂用产品名 **Dual UI**，npm scope 使用占位符 `@your-scope`，CSS 前缀暂定 `dui`。没有查询或占用这个包名，也没有替你注册账号。

## 已明确的用户需求

React 和 Vue 都可使用；同时适配 PC 与手机；通过 npm 供外部开发者安装；组件能高度定制；可修改完整主题；需要供 AI 实施的 Markdown 文档。

## 为避免项目失控，采用以下默认决策

| 事项 | 本项目决定 | 边界与后续调整 |
|---|---|---|
| 平台 | 浏览器 Web：PC、平板、移动 H5 | 不等于 React Native、原生 App、uni-app 或微信小程序原生组件 |
| 框架 | React 与 Vue 分别原生实现 | 不在 Vue 内嵌 React，不反向嵌套，不强行转换 JSX/SFC |
| 复用 | 共享 tokens、CSS、类型、纯逻辑与行为测试 | hooks、composables、生命周期、渲染和 ref 各自实现 |
| 仓库 | pnpm workspace monorepo | 首期不用微前端，不引入 Nx/Turborepo 等额外编排依赖 |
| 首发格式 | ESM + 类型声明 + 独立 CSS | 不承诺直接 `require()`、UMD/CDN 全局变量或 Vue 2 |
| 样式 | 原生 CSS + CSS 自定义属性 | 使用者无需 Tailwind、Less、Sass 或运行时 CSS-in-JS |
| 发布 | 4 个公共 npm 包，同版本发布组 | packages/internal-* 为私有工程包，不能遗留到运行时依赖 |
| 可定制 | tokens、命名部位、slots、组合 API、unstyled、源码二开 | 不承诺任意 DOM 改动仍保持可访问性 |
| 默认视觉 | 中性简洁，品牌色可替换 | 蓝色仅为示例预设，不作为用户已确认的品牌规范 |
| 许可证 | 计划 MIT | 发布前由所有者确认授权范围、署名和第三方许可证 |
| 国际化 | 简体中文、繁体中文、英文 | 支持 locale 接口与 RTL；不依赖在线翻译 |
| v1 范围 | P0 + P1 共 54 项 | P2 为后续 18 项；不要一次实现全部 72 项 |

## 版本基线与真实性

建议开发/发布使用 Node 24 LTS；兼容验证同时覆盖 Node 22 的受支持版本。React peer 目标 `^18.3.1 || ^19.0.0`，Vue peer 目标 `^3.5.0`。这是拟定支持区间，不是已经跑过测试的兼容承诺。执行 M0 时核对安全补丁、工具链要求、peerDependencies，再锁定具体版本。

npm、Vite、Storybook 等工具的配置会变化，不能把旧教程直接当作当前配置；参考 [核验记录](25-官方资料与核验记录.md)。不要使用浮动的 `latest` 做可重复发布。

## 必须由所有者完成或授权的外部操作

确认产品名、npm scope、GitHub 仓库归属、许可证署名；创建并保护 npm 账号；设置双因素认证；配置每个包的可信发布者；批准真正的公开发布。AI 不得捏造这些信息，不得把令牌写进仓库，也不得未经授权执行公开发布。

未定品牌色、Logo 或文案不妨碍本地骨架开发。使用明确标记的示例值；涉及付费、公开发布、删除资源和许可证变更时停在对应操作门禁，不阻断其他本地任务。
