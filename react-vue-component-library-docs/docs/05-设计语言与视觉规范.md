# 05｜设计语言与视觉规范

以下数值是本项目的初始设计决定，不是所有平台强制标准。品牌正式确认后改 token，不在每个组件改硬编码。

## 1. 视觉原则

中性底色、清晰层次、有限装饰；先保证信息和操作可辨识，再增加动画。使用系统字体栈，不分发商业字体。默认不使用表情包充当专业功能图标。图标和文字标签不能只靠颜色区分状态。

## 2. 尺度

| 维度 | 初始值 |
|---|---|
| 间距阶梯 | 0、2、4、8、12、16、20、24、32、40、48、64 CSS px |
| 正文字号 | 14 / 16；移动表单默认 16 |
| 标题字号 | 20 / 24 / 30 / 36；与语义 h1–h6 分开配置 |
| 行高 | 正文 1.5；短标题 1.25 |
| 圆角 | 0 / 4 / 8 / 12 / 16 / pill |
| 控件视觉高度 | sm 32、md 40、lg 48；触屏点击区域另行保证 |
| 移动触控目标 | 项目目标至少 44×44 CSS px，可通过外围区域实现 |
| 布局留白 | 手机 16；平板 24；桌面 24–32 |
| 主操作间距 | 默认 8；移动操作组可换行或纵排 |
| 面板宽度 | 不超过可视宽度减两侧安全留白 |
| 动画 | fast 120ms、normal 180ms、slow 240ms；支持关闭 |

在 320 CSS px 宽度及 200% 文字缩放下不隐藏关键动作。字号和尺寸允许用户覆盖；不能用固定高度裁切长标签、翻译或两行错误提示。

## 3. 状态视觉

每个可交互组件审查 default、hover、active、focus-visible、disabled、readonly、loading、invalid、selected/open。并非每个组件都有全部状态；单组件文档确定有效状态。

focus-visible 使用可辨识轮廓且不被 overflow 裁切；disabled 不只降低 opacity，还要阻止相应操作；readonly 仍支持选择/复制；loading 保留原按钮宽度和可读名称；invalid 使用图标或文案补充颜色。

## 4. 层级

基础内容 0、局部 sticky 10、普通浮层基础 1000、模态基础 1100、全局通知基础 1300、开发调试 2000。以上是起始 token，不是跨 DOM 的绝对保证。实际嵌套浮层由统一栈分配；模态内部 Select/Tooltip 必须在其模态上方，不能仅固定为 1000。

## 5. 默认主题与验收

提供 light/dark；默认中性表面配可替换品牌色；组件预览展示长文案、英文、繁体中文、错误、触屏尺寸和 RTL。主题切换不能改变语义结构，不允许为了“暗色”对整个页面反相滤镜。

默认预设按文本、图标、边界和焦点要求检查对比度；自定义主题不能宣称自动合规。组件展示必须包含“不符合对比度”的主题编辑器告警示例。无障碍指标详见 [无障碍规范](09-无障碍与键盘交互.md)。
