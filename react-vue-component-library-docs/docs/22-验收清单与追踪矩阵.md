## 2. 单组件 Definition of Done

- [ ] React 与 Vue 的公开 API、默认值、事件、实例方法一致映射。
- [ ] 有全部必需状态与真实交互；非空壳。
- [ ] 键盘、焦点、读屏名称、错误关联通过。
- [ ] PC/H5、明暗、局部主题、RTL、unstyled 通过。
- [ ] 类型、行为契约与具体边界案例通过。
- [ ] 子路径/CSS 导出、必要样式依赖、tree shaking 通过。
- [ ] 有双框架可运行示例、token/part/slot 文档。
- [ ] 无监听器、定时器、对象 URL 或滚动锁泄漏。
- [ ] 公共变更有 changeset，追踪信息附证据。

## 3. 发布阻断级别

P0：无法安装/构建、用户值错误或丢失、明显安全风险、键盘或焦点不可用、重复运行时、CSS 无法加载、SSR 严重失败。必须修复。

P1：承诺功能缺失、影响主要手机操作、两框架行为不一致、默认主题重要状态不可辨识、文档示例不能运行。稳定发布前修复或明确从版本范围移除并调整文档。

P2：不阻断主要路径的小视觉差异、文案优化、非承诺环境问题；记录 issue 与处理策略。缺少真实设备测试不降级伪装 P2，应标记未验证的兼容范围。

## 4. 验收结论模板

版本/commit；范围；工具和设备版本；通过列表；失败列表；未运行列表；风险；批准人。只有“通过”可以勾选，无证据写 not-run。截图只能证明特定视觉状态，不证明受控状态、npm 安装或 SSR 正确。
