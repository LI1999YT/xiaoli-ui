# 17｜文档站、Storybook 与示例工程

## 1. 信息架构

入门 → 安装 → React/Vue 切换 → 组件分类 → 主题与自定义 → 响应式 → 无障碍 → SSR → 按需加载 → 迁移 → 贡献。每页显示适用框架、引入路径、稳定级别、首次版本与最后核验版本。

文档门户可用 VitePress，React 和 Vue 示例分别在独立 Storybook/Playground 构建，通过链接或受控 iframe 展示。不要把 React runtime 和 Vue runtime 混入消费者库包。文档站用 Vue 不代表库使用者要安装 Vue。

Storybook 为两框架分别提供 Vite 集成，应使用各自配置而不是一个故事同时硬套两种渲染器。[React Vite](https://storybook.js.org/docs/get-started/frameworks/react-vite)；[Vue Vite](https://storybook.js.org/docs/get-started/frameworks/vue3-vite)。

## 2. 每个组件页面

简介与适用场景；版本/优先级；全量与按需引入；最小示例；变体/尺寸/状态；受控与非受控；移动展示；明暗与局部主题；部位、slots 与 unstyled；Props/Events/Methods/Types 表；无障碍与键盘；边界与限制；相关组件；迁移说明。

两框架示例必须来自可执行源码，不手写一份永远不编译的文档伪代码。复杂场景给完整 import、state、handler 与 CSS，不只截取一行组件调用。复制按钮只复制用户选中的框架和必要代码。

## 3. 全局交互

搜索组件与 API；主题/明暗/密度/语言/RTL 切换；PC 与手机预览视口；查看源码；复制安装与使用代码；按当前版本筛选。搜索本地索引起步，不默认接入需账号或付费的外部搜索。

URL 支持定位到组件和示例。演示页不使用真实个人数据。文档站在线 playground 若允许执行用户代码，必须使用 sandbox iframe、限制来源与权限；不要在文档门户同源主窗口直接 eval 未信任输入。

## 4. 示例应用

React 后台：筛选 Form + Table + Pagination + 编辑 Dialog + Toast；Vue 后台做语义等价版本。React/Vue H5：搜索、列表、详情 Card、表单、BottomSheet、TabBar。首个试点阶段使用 P0 范围组件，不提前依赖 P1 尚未实现的 Table。

主题示例：两个品牌同时存在、嵌套暗色、弹层内选择器、unstyled 表单、覆写部位；SSR 示例：Next.js / Nuxt 生产 build 与路由切换。

## 5. 质量

文档页无死链，示例无 console error；主题与组件状态同步；所有公开 props 都有说明，默认值来自一致来源。手机导航和复制按钮可触达，代码块仅局部横向滚动。

文档和 npm 发布版本关联，预览/实验组件显著标记，不让 users 复制尚未发布版本 API。未实现组件显示规划状态，不展示伪成功示例。
