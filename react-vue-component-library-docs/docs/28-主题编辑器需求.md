# 28｜主题编辑器与可视化配置需求

## 1. 定位

文档站中的主题预览工具，作为 M3 可选增强，不阻断 M1/M2。用于验证“高度自定义”是否真的可用；不是必须安装的运行时依赖，不发布进 ui-react/ui-vue 主入口。

## 2. 配置面板

品牌色与状态色、文本/背景/边框、字体与字号、间距、圆角、阴影、焦点、密度、尺寸、动效、明暗、RTL。高级模式显示组件级 token。所有控件从 schema 自动生成，数值输入有单位校验和范围提示。

提供 reset 单项、reset 整主题、复制 token 名、查看语义引用、恢复预设、撤销/重做。编辑器不能让组件样式绕过统一 token 路径，否则预览和真实 Provider 行为会分叉。

## 3. 实时预览

同时看 Button/Input/Select/Form/Dialog/Card/Table/Toast；切换 React/Vue；切换视口与状态；保留表单值；弹窗打开时改主题观察同步。演示可显示嵌套第二主题，用于验证作用域隔离。

未实现的 P1 组件不可用截图伪装成真实预览。第一阶段只展示完成并通过测试的组件。

## 4. 导入导出

JSON `{schemaVersion, id, mode, tokens, components}`；TypeScript defineTheme 代码；CSS 自定义属性。导入文件大小初始上限 100KiB；JSON 深度、键和类型有上限；拒绝函数、原型污染键、远程资源和 CSS 注入。

导出结果必须能在独立 fixture 导入，并得到相同外观。提供 diff 与迁移报告；不发送主题到服务器。可选 localStorage 保存由编辑器应用负责，使用命名空间和版本，捕获 quota/security 错误。

## 5. 主题质量提示

对比度不足提示具体前景/背景组合与测量值；不是只显示“绿色通过”却不测 hover/disabled/focus。颜色预设不能仅根据单一主色盲目生成所有状态并宣称合规。

不支持的 token 或无效单位必须标记，导出前阻止明显无效主题。可用性提示不是法律认证。
