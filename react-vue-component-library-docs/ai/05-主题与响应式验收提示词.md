# 主题与响应式专项验收提示词

```text
对当前实现执行主题、自定义与PC/H5专项验收。读取 docs/05、06、07、08、09、10、12、28 和相关组件规格。

建立双框架同一组演示：light/dark/system；两个品牌并排；嵌套反向主题；运行时更新与撤销token；更换主题不丢输入、选中、滚动和焦点。
在Dialog已打开且内部Select/Popover也打开时切换主题；验证portal host得到解析配置，外部任意CSS不会被错误宣传为自动继承。
测试color/type/radius/spacing/density/shadow/motion/组件token/parts/slots与unstyled，检查无全局reset污染。

视口覆盖320、390、768、1280、1920及横竖屏；浏览器缩放与长中英文文本；触控命中区、safe-area、软键盘、低动效、RTL、强制色模式。
CSS媒体查询断点为构建期配置，不把运行时CSS变量写入普通@media当作已支持。hover与触控能力分开判断，避免按UA猜布局。
手势组件有点击/键盘替代；不能为满足窄屏截图裁掉内容或隐藏必要操作。

先列用例再实际运行；自动化结果与真机/读屏结果分别记。主题色值和截图不证明对比度合规，须检查实际计算样式及不同状态。
把错误形成可重现用例并修复；记录真实设备/系统/浏览器/版本/操作步骤和未验证范围，不声称模拟器等于真机。
使用 templates/测试报告模板.md 生成报告并更新tracking；不以美观主观评价代替功能验收。
```
