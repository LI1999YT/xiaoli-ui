# 代码审查与修复提示词

```text
请对当前分支做组件库专项审查，先读AGENTS、tracking与相关规格，再检查真实代码、测试和打包产物。不要仅重复上次AI的完成报告。

按严重程度输出问题：阻断安装/数据/焦点/安全的问题优先，其次API与兼容承诺不符，再是非阻断视觉问题。每个问题给文件位置、触发场景、预期与实际、修复建议和必要回归测试。

重点审查：
1. React/Vue是否互相依赖、框架运行时是否被打包、私有/workspace依赖是否泄漏。
2. 受控状态、VueBoolean默认、双重通知、IME、null/0/false、props变更和reset。
3. Provider/Portal主题、嵌套弹层、Escape只关顶层、焦点恢复、scrolllock与资源清理。
4. SSR顶层DOM访问、并发请求状态污染、hydration、React client边界、VueTeleport限制。
5. CSS全量/按需、样式优先级、token别名、unstyled必要结构、强制色/RTL/触控与软键盘。
6. 泛型声明、子路径、外部consumer实际安装、peer组合、sideEffects与包体。
7. 未覆盖的复杂边界、假测试/空实现、未验证兼容声明、许可证与凭证泄漏。

先验证问题再修复；保留用户现有改动。用最小可复现测试说明根因，不仅包一层try/catch或as any。
不能为通过而删除失败测试、全量接受视觉差异、关闭SSR、加全局!important、改用另一框架或清空lockfile。
修复后跑受影响测试与必要全回归，记录未运行项与原因；更新tracking和有破坏性变化的changeset/迁移文档。
```
