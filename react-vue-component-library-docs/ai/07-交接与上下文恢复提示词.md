# 交接与上下文恢复提示词

## 结束一次会话

```text
请为本次工作生成可继续执行的交接记录并更新tracking，不能凭印象标记完成。
包含：当前分支/commit/是否有未提交改动、完成任务与关键文件、执行的精确命令/结果/日志、失败与未运行项、API/架构决定及理由、临时实现和不能删除的用户改动、外部账号/真机阻塞、下一项可执行任务和验收条件。
把决定放DECISIONS、阻塞放BLOCKERS、任务结果放TASKS、当前摘要放STATUS；不要把四份文档复制成同一段话。
有新公开API或代码行为变化同步规格和changeset，不能只写在聊天里。不要保存密码、token、OTP或私有业务数据。
```

## 新会话恢复

```text
请接手当前仓库，不要重新生成全部文件。先读取AGENTS、START_HERE和tracking全部状态文件，检查Git与实际代码。
核查上次“通过”的证据是否对应当前commit；缺证据或代码已改变则标为待复核，不无条件信任旧总结。
从TASKS选第一个依赖满足且未完成的任务，读取对应docs与components规格，给本次范围并继续实际开发。
保留用户改动和已批准决定，不改框架/包结构/主题接口来节省工作。无法读取的文件、失败命令或缺少权限明确报告，不猜测其内容。
完成后按单组件/阶段DoD运行真实检查并更新追踪；无发布授权不进行任何公开npm操作。
```
