# 从这里开始｜把这套文档交给 AI 开发

## 这是什么

这是一套可直接用于 AI 编程协作的需求与工程文档，不是已经写好的组件库源码。目标是 React + Vue 原生双实现、PC/平板/手机 H5 适配、完整主题定制及 npm 分发。所有兼容范围和性能数值是待实施、待验证的目标。

最重要的选择已经做出：**先搭共享底座和十项纵向试点，再扩到基础 26 项，最后完成 1.0 的 54 项；不要一次性让 AI 生成 72 项然后直接发布。**

## 第一步：放进项目根目录

新建一个空项目目录，例如 `dual-ui`；解压文档压缩包，将包内 `AGENTS.md`、`README.md`、`docs/`、`components/`、`ai/`、`templates/`、`tracking/` 等内容放在该目录根部。不是把所有文件混成一个 MD，也不是只把 ZIP 文件名告诉 AI。

在具有本地文件读取、编辑和终端执行能力的 AI 编程工具里打开该目录。若工具只有聊天能力，它可以写方案/代码文本，但你仍需实际创建文件、执行命令和检查结果；不要把“回答了代码”当作已经改了本地仓库。

已有项目应使用单独分支并先保留现有改动；此文档中的目录是目标结构，不授权覆盖你的业务仓库。

## 第二步：填写少量项目身份信息

在 [DECISIONS](tracking/DECISIONS.md) 填组件库名称、npm scope、仓库位置和许可证决定。尚未确定时可沿用占位继续本地开发；实际发布前必须全部替换并验证 scope 权限。默认建议 MIT，但许可证必须由你确认。品牌主色、图标来源和主题预设可后续细化，不能使用来源不明素材。

开发阶段无须把 npm 密码、验证码、写 token 给 AI。登录与批准由你在可信终端/平台完成。

## 第三步：先发送总控提示词

打开并复制 [AI 总控启动提示词](ai/01-总控启动提示词.md)。首次只要求 **M0 工程底座**；M0 通过后才用 [分阶段执行提示词](ai/02-分阶段执行提示词.md) 推进 M1。

可以先发送下面这段：

```text
请把当前目录作为组件库项目根目录，先读取 AGENTS.md、START_HERE.md、
tracking 下的状态与决策，再读取 docs/00、02、03、04、06、14、15、21、29 对应文档。
按这些规格实际创建文件并实现 M0，不要只复述方案，不要一次性生成全部组件。
先检查已有文件，核验并锁定工具版本；完成 workspace、四个公开包、共享主题基础、
双框架最小消费示例、测试与打包脚本。内部脚手架不能伪装稳定 API。
运行能够实际执行的安装、类型、构建、pack 与 consumer 检查；保留真实日志。
更新 tracking 状态，明确哪些通过、失败、未运行或受阻。不要擅自公开发布 npm。
```

## 第四步：用交付证据判断 AI 是否完成

要求 AI 展示修改文件、实际命令与结果、双框架可操作示例、tarball 的消费验证、未解决问题。不是“创建了很多文件”“截图看起来正常”“没有明显报错”就算完成。

M1 的串联场景必须在 React/Vue 都能操作：输入姓名与勾选 → 验证 → 弹出确认框 → 提交反馈；两个局部主题同时显示，已经打开的弹窗随主题切换，键盘能完成全过程。

遇到问题用 [审查与修复提示词](ai/04-代码审查与修复提示词.md)；会话太长或换 AI 时用 [交接提示词](ai/07-交接与上下文恢复提示词.md)，从 tracking 恢复，而不是重新从零生成。

## 第五步：再进入 npm 发布

先读 [npm 发布操作手册](docs/19-npm发布操作手册.md) 和 [发布检查表](tracking/RELEASE-CHECKLIST.md)。本地打包→独立项目安装→预发布 next→稳定发布 latest；每一层都要有真实验证。

真实包名、仓库权限、npm allowed actions、版本、受保护工作流和 tarball 内容未核实前，不执行 publish。修改 dist-tag 不是已安装用户的自动回滚。实现 AI 应按发布当天官方文档重新核对规则。

## 你会得到的成品是什么

用户只装自己需要的 React 或 Vue 包，并显式导入 CSS；可调整颜色、字号、间距、密度、圆角、阴影、动效、组件部位，支持明暗/系统主题和局部主题。桌面与手机共用值模型，可在 Select/日期等场景切换合适的浮层展示。

本需求不包括 React Native、微信小程序原生组件、后端服务、账户系统或已经注册成功的 npm 名称。未来增加这些范围要另立方案，不能因为“React”或“移动端”几个字就声称已经兼容。

总目录见 [README](README.md)；组件逐项规格见 [组件索引](components/README.md)。
