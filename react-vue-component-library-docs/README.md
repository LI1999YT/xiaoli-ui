# React + Vue 双框架组件库｜需求与 AI 开发文档包

**125 份 Markdown · 72 项组件规格 · 30 份核心规范。**文档基线：2026-09-10。

目标：双框架原生组件、PC/平板/手机 H5、完整主题/高度自定义、可测试且可公开分发的 npm 包。

**当前交付是文档，不是组件源码；未执行组件构建/测试，未注册包名或发布 npm。**组件和工程任务均保留待实施状态。版本/工具/发布规则以正式实施当天复核结果为准。

## 先打开哪份

第一次使用读 [START_HERE](START_HERE.md)，再把 [总控启动提示词](ai/01-总控启动提示词.md) 交给能操作文件与终端的 AI；开发规则在 [AGENTS](AGENTS.md)。查某个组件读 [72 项组件索引](components/README.md)。

## 推荐路线

M0 底座 → M1 十项双框架试点 → M2 P0共26项 → M3 P0+P1共54项的1.0候选 → M4 后续18项扩展。每阶段按退出条件推进；公开发布必须另获授权。

试点：ConfigProvider、Button、Icon、Input、Checkbox、Form、Dialog、Toast、Flex、Card。串联表单/确认/反馈/主题完整体验，而不是先批量创建空组件。

## 使用边界

暂用 Dual UI、@your-scope 和 dui，不表示已注册或用户已确认品牌。移动端为网页/H5，不直接适配 React Native / 原生小程序。兼容矩阵、性能预算与无障碍要求均为待验证目标；文档包的内部链接校验不是软件质量认证。

技术事实的官方资料及核验日期见 [官方资料](docs/25-官方资料与核验记录.md)；本包文件结构检查见 [文档校验报告](DOCUMENTATION_QA.md)。
